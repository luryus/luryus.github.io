My projects

wden

A password manager TUI for Bitwarden-compatible servers. A lot more lightweight than official Bitwarden client apps. Written in Rust using the Cursive framework.

Wattiviisari

A Wear OS (Android Wear) app for viewing Finnish electricity spot prices.

RP-FC Footswitch

A GA-FC footswitch clone for Boss Katana amps, built around a Raspberry Pi Pico using embedded Rust.

Raspberry Pi Pico Macropad

I built a Raspberry Pi Pico based macropad for my own use. It has a completely custom firmware that handles the keyboard, rotary encoders, the user interface, and USB communication with the host. It works together with a Python-based server program that handles application-specific shortcuts and macros.

udp-bcast-relay-rs

A Rust reimplementation of the udp-broadcast-relay project. Used in my fork of the ubnt-bcast-relay project for Ubiquiti EdgeRouters. The upstream project ships prebuilt binaries that I'm not keen on installing to my routers. And cross-compiling the C project to the MIPS architecture on EdgeRouter X is non-trivial. So I ended up rewriting it in Rust just because that was more fun than setting up the build environment for the upstream project.
